# Garden art

`spring-garden-v1.png` was created with the built-in ImageGen tool for this project. Earlier dark/painterly drafts were rejected and are not shipped.

The garden now has 17 ordinary plant species. The nine original atlases were edited with ImageGen to remove their fairy characters; runtime uses only four ordinary growth cells. Eight regional species use two new transparent atlases. No fairy variants are displayed or generated by planting. See [REGIONAL-WORLDS-V1.md](REGIONAL-WORLDS-V1.md) for the current assets and [the desktop guide](../../../docs/desktop-garden.md) for 3D rendering. No runtime image generation or external asset requests are required.
