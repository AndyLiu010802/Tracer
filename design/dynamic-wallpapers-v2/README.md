# 流动的光 · 粒子系列

当前版本 `motionVersion: 5`。十款动态壁纸全部由 Canvas 2D 实时绘制，以流线、细尘、光雾的不同构图与节奏区分风格。动态背景不再加载照片，也不使用照片扭曲或镜头往返移动。

运行 `node design/dynamic-wallpapers-v2/preview.cjs`，打开输出地址浏览十款效果，支持暂停、全屏与系统减少动态效果设置。此目录名称保留以兼容已有预览链接。

| 编号 | 风格 |
| --- | --- |
| d01 | 流光丝幕：青绿与紫罗兰的细线光幕 |
| d02 | 蓝调光雨：蓝色垂直光线与零星暖金 |
| d03 | 翠影微尘：翡翠色粒子回旋 |
| d04 | 玫瑰绡光：烟粉光雾与斜向轻纱 |

| d10 | 香槟轨迹：金色椭圆轨迹与游走光点 |

实现仅依赖 `skins/tracer/wallpaper-motion.js`。商品编号、价格及所有权记录不变；旧照片资产保留作历史设计资料，当前动态商品不引用它们。`update-catalog.cjs` 同步应用与预览的文案、版本和元数据。

播放器上限 30 fps，像素比上限 1.5，画布宽度上限 1920、高度上限 1600。暂停、页面隐藏、离开视口及系统减少动态时停止循环；光斑纹理缓存复用，销毁时释放观察器与事件监听。

验证：`dev/qa-wallpaper-motion.cjs` 检查十款效果、时间连续性、不透明覆盖、确定性、暂停/减少动态、离屏停止、销毁、快速切换与尺寸上限；`dev/qa-material-contrast.cjs` 覆盖十种材质下的十个页面和四类弹窗文字。
