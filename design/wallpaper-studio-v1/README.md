# Tracer 风景收藏馆 · 第一版

交付 30 款设计：10 张独立静态 PNG、10 款可运行 Canvas 动态壁纸、10 套覆盖任务界面的 CSS 材质与边框主题。动态壁纸已升级为第五版抽象粒子系列，逐款说明与独立预览位于 `../dynamic-wallpapers-v2/`。

双击 `index.html` 即可打开，无需安装依赖或联网。选择分类和款式后，顶部显示完整预览；支持隐藏任务界面、调整背景遮罩、放大、暂停动态和保存本机心愿单。`wallpaper.html#d01` 至 `#d10` 可以单独展示动态壁纸。

当前交付是可交互设计原型。账户注册、真实扣款、云端所有权和正式应用换肤尚未接入；原型只在自己的 localStorage 键中保存心愿单，不读取或修改真实任务、金币、账户或花园存档。

## 文件

- `index.html`、`studio.css`、`studio.js`：预览画廊。
- `catalog.js`、`catalog.json`：30 款的编号、名称、配色、建议价格、描述与效果标识。
- `assets/static-01.png` 至 `static-10.png`：10 张静态原图，宽 1672、高 940–941 像素，约 16:9。
- `wallpaper.html`：动态预览，直接引用应用的 `../../skins/tracer/wallpaper-motion.js`。预览卡片显示静帧；仅主预览播放，减少并行渲染。旧 `motion.js` 为历史版本，不再加载。
- `image-prompts.json`：10 张静态壁纸的生成提示词与来源路径；使用内置 image_gen 生成。当前动态壁纸完全由 Canvas 绘制，旧照片及提示词只作为历史设计资料保留；材质使用 CSS。
- `ACCOUNT-SHOP-SPEC.md`：账户、金币和壁纸商店的开发规格。
- `previews/`：检查后的画廊截图和分类总览。

## 动态与外观规则

动态不播放声音。暂停后保留当前画面；页面隐藏、离开视口、系统偏好减少动态时停止动画。像素比例上限 1.5。正式应用还需接入 Electron 最小化、锁屏、节能模式和设备性能检测；浏览器原型未验证这些原生事件。

材质款包括背景、顶栏、侧栏、任务卡片、专注卡片、边框；正式版应继续覆盖笔记、日程、弹窗、输入框、滚动条、悬停/禁用/焦点等状态。当前画廊展示代表性任务页面，尚未覆盖全部正式应用页面。

静态原图可下载。动态是实时程序画面，没有声称交付 MP4/WebM。材质主题在 `studio.css` 的 `data-material` 规则中，可移植为应用主题变量；未直接修改当前应用样式。

所有价格为方案值：静态 60–100、动态 140–220、材质 240–360 花园金币。后续按实际获得金币的速度调整，不影响已购权益。
