# Tracer 0.4.5 — Windows x64

- 新增可搬到桌面的 3D 花园，支持拖动窗口、旋转岛屿、缩放及直接收获。
- 六个地区采用不同地面材质与建筑，增加地形起伏、自然岸边、石板小径、屋瓦和门廊细节。
- 新增椰子树、珊瑚扶桑、樱花树、紫藤、雪绒花、雪松、金琥仙人球、沙漠玫瑰八种地区植物；种花只产出植物，移除花精灵图像。
- 丰富项目星球的地区风貌与自然过渡；明信片增至十二款，可放置、移动、缩放和旋转已有贴纸。
- 神秘礼包增加多个金币档位，其中 50,000 金币的概率为 0.1%，按收据唯一入账。
- 桌面花园按需绘制，隐藏或锁定账户时释放图形资源，并支持图形上下文恢复。

完整回归通过 1,489 项核心测试及 68 项桌面测试。真实 Electron 桌面验收覆盖收获、旋转、缩放、空闲停止绘制、六地区呈现、图形恢复与账户锁定；浏览器验收覆盖明信片贴纸编辑、保存、导出和移动端布局。构建后另核对安装包内源文件、全部 879 个花园/钓鱼资源、隐私隔离及内置运行时。

本次提供 Windows x64。安装前从托盘完全退出旧版，再安装到原位置；继续使用 `%APPDATA%\tracer-desktop-commercial\`，从 0.4.4 更新沿用原分发版存档。源码及更早版本的独立目录不自动迁入。

安装包尚未使用 Windows 代码签名证书签名。SHA-256 校验用于确认下载完整性，不能替代发布者数字签名。下载 `Tracer-Setup-0.4.5-x64.exe` 即可安装；`.blockmap` 无需单独下载。

玩法、地区价格和控制方式见[桌面花园说明](desktop-garden.md)。
