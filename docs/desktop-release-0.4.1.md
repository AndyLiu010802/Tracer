# Tracer 0.4.1 — Windows 更新

本次先提供 Windows x64 安装包，包含当前伙伴资源更新、新贴纸、花园伙伴聊天身份修复，以及拖尾流畅度与低开销优化。Mac 暂时保留已发布的 0.4.0 版本。

## 更新内容

- 新增生活、宠物与旅行主题贴纸，提供纸质和闪光两种风格。
- 花园伙伴聊天按当前伙伴的名称、品种与普通／异色身份回答，修复苹宝误称芽芽等对应错误。
- 霓虹蝶兰改用圆润透明花瓣、连续光带与柔和渐隐，减少转弯棱角和尾部消退时的跳动。
- 拖尾移动时以 60 帧为目标；静止后降低位置检查频率，粒子消散后停止绘制。缓存光带和渐变，减少绘制调用，并限制高分屏画布像素数。
- 包含当前内置与花园伙伴动作资源、账户和任务花园的改进。

## 安装

下载 `Tracer-Setup-0.4.1-x64.exe`，从系统托盘完全退出旧版后安装到原位置。已有任务、笔记、账户、伙伴和购买记录保留；无需另装 Node.js 或 Codex。

`SHA256SUMS-0.4.1.txt` 用于核对安装包和 blockmap 校验值；blockmap 无需单独安装。Windows 安装包目前未签名。

## 验证

703 项核心测试与 25 项桌面测试通过。贴纸、花园伙伴身份、九款拖尾和平滑度专项回归已通过；拖尾性能检查覆盖 60、120、144 Hz 调度、粒子上限、静止恢复和结束清理。

拖尾本机浏览器基准中，CPU 绘制提交耗时比此前 60 帧版本减少约 25%–27%；DPR 2 的 1080p 逻辑画布像素数减少约 44%。这些数值不代表整机 GPU 占用降幅。[性能验证说明](https://github.com/AndyLiu010802/Tracer/blob/v0.4.1/docs/shiny-companion-trails.md)。
