# 历史发布说明

`release-notes-through-0.3.7.zip` 合并保存了先前归档的 0.2.0 至 0.3.4 发布说明、原 `dist/README-0.2.0.md`，以及 0.3.6、0.3.7 发布说明，共九份文件。压缩包保留原始相对路径和文件内容，需要查阅时可解压到临时目录。历史说明中的功能和路径仅代表当时版本。

当前版本请查看 [0.3.9 发布说明](../desktop-release-0.3.9.md) 和 [Mac 安装指南](../macos-install.md)。0.3.9 新增伙伴聊天追问、方案预览和确认创建任务或项目，以及本地会话恢复与同请求重试；已移除微信小程序模块。[0.3.9 下载入口](https://github.com/AndyLiu010802/Tracer/releases/tag/v0.3.9)已提供通过三平台构建和验收的完整安装包。

[0.3.8 发布说明](../desktop-release-0.3.8.md)保留单动作重生成与旧帧兼容的历史记录。旧版构建目录不代表当前安装包。

`history-design-notes.zip` 保留原 `docs/superpowers/` 下的 27 份历史计划、设计规格、素材提示和交接说明。所有原路径与字节已逐项核对；这些文件记录早期设计，不作为当前功能或构建说明。
