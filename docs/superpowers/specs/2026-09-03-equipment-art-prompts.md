# 装备图标 · 出图 Prompt（30 件）

配套 spec：`2026-09-03-forge-equipment-design.md`。5 槽 × 6 档 = 30 件物品图标。
和材料/战利品同一「物品图标」画风。出图 `1024×1024` 透明底，命名 `<key>.webp` 放 `skins/db-console/equip/`。
越高档越华丽/奇幻，但保持同一扁平矢量画风。

## 【物品风格圣经】（每条前逐字照抄）
```
Flat vector game equipment / item icon of a single object, centered, on a pure transparent background. Clean thick dark outline, smooth cel-shaded flat color fills, soft top light with a subtle inner glow. Cohesive muted palette with one accent hue. Bold, readable silhouette that stays legible when shrunk to 32 pixels. No ground, no cast shadow, no scenery, no text, no letters, no watermark, no UI, no border, no frame. Square 1:1 composition, the object filling about 72% of the frame. The art style must be identical across all thirty items. Higher-tier pieces are more ornate but keep the exact same flat-vector style.
Negative: no photorealism, no 3D render, no background, no text, no multiple objects, no hands wearing it, not cropped.
```
