# 海贼王鱼竿流畅度优化

> 旧弹窗验证入口已退役；本文中的相关命令为历史记录。当前验证方式见 [桌面与原画验证](fishing-live-species-upgrade.md)。

移除了原画鱼竿加载时用不到的三维模型、材质着色器和阴影图初始化。正常图片加载时使用原画渲染；图片失败时仍回退到立体模型。

完整武器改为一个仿射贴图面，软件绘制从每帧 128 次降到 1 次。普通竿型保留 64 段弯曲曲线，将不变握柄合并绘制，动态部分只采样对应图片区域；本轮抽样款为 91 次绘制。纹理、UV、顶点缓存和显卡缓冲区复用，连续动作不再反复申请显卡缓冲。软件渲染也按连续弯曲值更新。

## 验证

- 原画文件未修改，曲线仍使用原来的 64 段模型；完整武器保持刚性。
- 骨架采样对照最大偏差约 0.000028 模型像素，仅为浮点误差。
- 两种渲染模式验证了加载、主题切换、图片失败、快速换竿、销毁后异步回调和显卡上下文丢失。
- 软件和显卡路径共 270 次原画渲染，无空白、裁边或页面错误。
- 追加了绘图缓冲复用、UV 稳定性、完整武器单次绘制、握柄批处理和显卡资源释放测试。
- 全量测试 1403 项、桌面测试 57 项全部通过；重新生成图鉴资源后，资源一致性和原画渲染专项检查通过。
- 实际游戏与桌面鱼塘运行脚本通过 120 个动作状态、38 款鱼漂、6 个钓场和 5 种盲盒品质显示检查。
