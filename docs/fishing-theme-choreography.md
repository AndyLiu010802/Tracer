# 鱼竿主题动作

> 旧弹窗验证入口已退役；本文中的相关命令为历史记录。当前验证方式见 [桌面与原画验证](fishing-live-species-upgrade.md)。

`skins/tracer/fishing-rod-effects.js` 共用同一套动作姿态驱动召唤、抛竿和捕获特效。透明度只处理开始和结束；中段始终有可见的几何变化。此次继续使用已确认的晶体神灵素材，没有新增拼接图片。

| 鱼竿 | 实际动作与表面细节 |
| --- | --- |
| 月轮星纱 | 曲面月相明暗交界移动，双轨道按深度前后穿越，星纱顺轨道偏移；表面保留细小环形纹理。 |
| 赤羽凤鸣 | 网格从翅根向翼尖渐变扇动，尾羽有相位差；抛竿时有带羽轴、羽枝的火羽掠过，捕获时凤凰现身。 |
| 云海御风 | 银白苍青的龙卷风，上宽下窄的连续云体包裹风眼，螺旋风带区分远近明暗。召唤时聚风升起、收束凝竿；抛竿带出旋风，上钩和收获时旋流卷起，退场反向散回风中。 |
| 银河织梦 | 三轴天仪旋转、透视缩放、远近轨道深度区别、轨道卫星及环上刻度。 |
| 九霄龙吟 | 雷金晶体龙身连续盘卷，身体起伏与投影压缩连动，周围雷弧随盘卷移动。 |
| 太虚莲华 | 三层共 21 片有叶脉的花瓣依次展开，内瓣延迟、末段合拢成杯，底部水纹扩散。 |
| 青龙偃月刀 | 青龙连续网格盘卷化兵，捕获时龙身起伏；劈波刀弧沿刀尖逐段扫出，双侧水纹随之分开。 |
| 武士刀·居合 | 先裂开空间，再拔刃，刀光追随刀尖而非整幅一起出现；召唤裂隙沿真实杆身定位。 |
| 黄金竿·万金之王 | 财神托起元宝、袖摆连动；捕获仍是单枚带厚度、边齿与浮雕的旋转金币，维持简洁奢华。 |

晶体角色仍是 40 × 48 连续网格，保留原有半透明密度与神灵形象。动作接口 `themePose` 在减少动态效果模式下固定姿态，避免快速转动与振翅。控制器、禁止召唤中钓鱼、无召唤进度条、5 秒待机退场、咬钩提示均未改动。

验证：`node --test test/fishing-rod-effects.test.js test/fishing-motion.test.js`；`node dev/qa-fishing-summon.cjs`；`node dev/qa-fishing-theme-actions.cjs`。后者同时检查 9 款鱼竿的三种动作阶段、可见几何变化、减少动态效果模式，以及 WebGL 资源成对释放和重复销毁安全性。输出在 `.cache/fishing-theme-actions/`。

`node dev/qa-fishing-tornado.cjs` 专门检查云海御风的龙卷风：实际桌面召唤与退场、桌面和面板的抛竿/上钩/收获、紧凑尺寸下的位置与裁切、减少动态效果模式，并输出多阶段画面对照。
