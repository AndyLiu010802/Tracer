# 壁纸可见度与动态系列 v6

「心愿商店 → 风景画廊」和「账户 → 装扮收藏」提供壁纸不透明度滑杆：0%–100%，默认 85%，支持键盘调节和一键恢复。滑杆旁的当前壁纸小样同步显示调整结果。设置按当前本地账户保存在 `tracer.wallpaperOpacity`，静态、动态壁纸共用；刷新和换壁纸后保留。

原先主内容区 86%–97% 的遮罩会掩盖壁纸。现在深色页面底色占比为 28%，浅色材质为 58%；标题、辅助文字和任务卡保留独立阅读底色。透明度只改变壁纸层，不改变文字或任务框。
