# Tracer 0.4.2 — 桌面钓鱼、万象秘藏与传奇水族箱

本次提供 Windows x64 安装包，将桌面钓鱼、鱼塘收藏和传奇水族箱整合到任务花园。Mac 继续使用已发布的 0.4.0 版本。

## 更新内容

- 桌面水塘支持左键拖动、右键操作和缩放。先召唤鱼竿，成形后才能钓鱼；召唤期间不显示进度条，闲置五秒会播放退场动画。
- 38 款鱼竿共用弯曲骨架，商店、图鉴与钓鱼场景使用同一套立体造型。各款具有独立结构、瓷釉、皮革缝线、金属包口、镂空护翼或玻璃晶腔。
- 新增独立「万象秘藏」奖池，共 20 款：3 款寻常、4 款珍稀、10 款史诗、3 款传奇。基础池继续保留，两池分别计算保底，同品质优先获得尚未收藏的款式。新池含一款 0.5% 隐藏传奇，获得前不展示名称或造型。
- 十款新史诗采用烛龙、雷鼓、玄鲸、枫火狐、铃兰、时轮、霜狼、蔷薇、墨羽与琉光蝶主题，公开传奇为曜日天铸与沧溟海皇。史诗以上各有专属召唤、退场与钓鱼动作，兽灵的颈、翼、尾、鳍、颚以及鼓槌、花铃、锻锤分别联动。
- 居合重做蓄势、拔刀、斩切、空间错位与收刀的连续动作，加入红黑水晶材质的地狱修罗虚影。原有青龙化兵、凤凰展翼、财神虚影继续保留；云海御风改为连续旋转的龙卷风。
- 支持 F、空格和鼠标控竿。鱼获展示后留有停顿，避免连续按键跳过结果。不同稀有度采用不同的巡游、冲刺、回气与追踪难度。
- 修复快速按下、松开 F 时，抛竿输入可能早于主窗口同步而丢失的问题。主窗口鱼塘与水族箱在钓鱼状态更新时复用渲染器，减少低性能设备上的卡顿；短时鱼获复用同一立体模型生成的预览，保留飞出、旋转与落地动作，避免另建渲染上下文拖慢按键或跳过展示。召唤原画按装备预加载并共用有界缓存。
- 六种鱼塘拥有独立场景。珍稀、史诗鱼捕获后额外获得鱼苗，可从鱼塘左侧育养箱放养；成鱼出售不影响已获得的鱼苗。
- 传奇水族箱可入住三条传奇鱼，提供十二种装饰。鱼有游泳、待机与玩耍动作；玻璃、水面、砂床与木质底座共享立体光照和阴影。
- 水族箱可作为桌面摆件拖动、缩放和隐藏，右键每次向左或向右旋转 15°，保存位置、大小和角度。
- 鱼竿盲盒降低重复奖励，黄金隐藏款概率为 0.5%，钓获鱼的售价翻倍。新增三种随机外观的杂物与神秘大礼包；礼包含六款专属头像框和背景，商店不可购买或预览。
- 植物与鱼支持全部出售，出售传奇鱼保留提醒。退休的角色桌宠、花精灵和伙伴生成界面及旧资源已清理，任务花园、植物图鉴和历史备份兼容继续保留。

## 安装

下载 `Tracer-Setup-0.4.2-x64.exe`，从系统托盘完全退出旧版后安装到原位置，无需另装 Node.js 或 Codex。

0.4.2 分发版使用独立目录 `%APPDATA%\tracer-desktop-commercial\`。旧版与源码运行的存档仍保留在 `%APPDATA%\tracer-desktop\`，不会自动迁入新目录；首次打开分发版会进入独立工作区。本机快照恢复只支持原安装中的同一空间，不能用于跨目录迁移。

`SHA256SUMS-0.4.2.txt` 提供安装包和 blockmap 的 SHA-256 校验值；blockmap 无需单独安装。Windows 安装包目前未签名。

## 发布验证

本机验证包含新奖池真实购买、装备与重载，隐藏款遮挡、独立保底、旧存档和中英文窄屏布局；20 款新模型逐款检查 WebGL、Canvas 降级、最大弯曲和 GPU 资源释放。打包规则核对 68 项花园／钓鱼资源，商业包另校验运行文件与内置官方组件，并生成安装包与 blockmap 的 SHA-256 校验值。

发布流程重复执行隔离测试和包内容校验，随后在打包后的应用验证启动、桌面钓鱼、水族箱、托盘与后台计时。本地实验入口、个人配置、账户和工作区数据不进入安装包；公开源码不包含私人参考美术，相关可选一致性检查只在本地素材存在时执行。
