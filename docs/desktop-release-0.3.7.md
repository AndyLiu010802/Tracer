# Tracer 0.3.7

本次更新为伙伴生成加入后台进度和草稿恢复，支持 Windows x64、Apple 芯片 Mac 和 Intel Mac。

- 关闭生成窗口、按 Esc 或点击遮罩只会收起界面，生成继续运行。导航栏显示已完成动作数，点击即可返回。
- 16 个动作完成后自动打开预览；若正在编辑其他内容，会等该编辑窗口关闭后再打开，避免覆盖输入。
- 未保存就关闭时提醒保存，照片、设置和生成结果继续保留。
- 本机草稿在生成前及每个动作完成后保存，重新打开应用可恢复已完成动作。继续生成需要用户点击，不会自动消耗额度。
- 重连请求复用服务端已完成的结果。重新生成、丢弃草稿或更换会影响已生成动作的设置都需要确认。
- 保存失败时保留预览和全部动作；保存成功后清除本机恢复草稿及其参考照片。

生成草稿包含缩放后的参考照片，仅保存在本机。生成图片时仍使用用户明确选择的账号或 API；不会自动更换服务。完整退出或强制关闭应用可能中断尚未完成的动作，已暂存的动作会保留。

仍支持 6 个内置伙伴的每动作 16 帧，以及新生成伙伴的 16 种动作、每动作 16 帧。旧版伙伴继续兼容。

升级前从托盘或应用菜单退出旧版，安装到原位置可保留已有任务、设置与伙伴。Windows 安装程序未签名；Mac 安装包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名和公证。详见 [Mac 安装指南](macos-install.md)。

发布附件包含 Windows EXE、Apple 芯片和 Intel Mac 各自的 DMG/ZIP，以及统一 SHA-256 校验文件。自动发布流程要求三个平台的单元测试、打包验证、原生桌宠检查和草稿恢复界面检查全部通过。
