# 本机快照备份与恢复（第一版）

这版解决误改后的工作区回退。只支持**当前 Tracer 安装、同一账户或同一游客空间**；不是跨电脑、重装、账户迁移或整机灾难恢复。不要删除本机账户目录后再尝试用这份文件重建账户。

## 使用方式

1. 点击右上角账户头像。游客直接选择“备份与恢复游客空间”；已登录用户进入“我的数据 → 备份与恢复”。
2. 选择“下载备份”，将 JSON 文件另存到合适位置。先等待未保存的工作区和伙伴草稿保存完成。
3. 恢复时选择文件，核对备份日期、任务/项目/笔记/收集项数量和包含范围。
4. 勾选确认，再点击“保存快照并恢复”。恢复成功后页面重新加载，其他旧窗口停止保存，专注计时不会自动启动或响铃。
5. 想撤销本次恢复，可打开“恢复前的快照”，下载对应快照，再按同样步骤预览和恢复。

文件未加密，包含任务和笔记内容，请按个人数据保管。恢复时，原有金币、出售记录和各类收藏会整体回到备份时点，不与当前资产叠加。

## 包含范围

| 内容 | 行为 |
| --- | --- |
| 任务、项目、笔记、收集项 | 恢复备份中支持的工作区字段 |
| 完成历史、项目删除记录、AI 创建回执 | 随工作区一起恢复 |
| 花园种子、收获、星球、金币账本、商店收藏和外观 | 整体恢复同一份快照；不混合当前账本，不重复发放 |
| 专注历史、累计时长、轮次及计时设置 | 恢复；运行中的计时改为暂停，清除待响闹钟，不补算离线专注 |
| 语言、入门引导状态、背景卡、侧栏宽度/折叠、花园可见性、壁纸显示设置 | 按明确白名单恢复 |
| 账户资料、密码、恢复码、会话、AI 密钥和许可证 | 不导出、不恢复；账户身份与当前授权保持独立 |
| 自定义伙伴图片、伙伴养成和选择、生成草稿、聊天记录 | 不包含，现有本机资源保留；自定义伙伴需使用独立伙伴包导出 |
| 音乐文件及播放设置、阅读书签、桌面窗口位置、其他偏好 | 不包含，现有值保留 |
| 旧工作区和旧云同步草稿、未提交引导标题 | 恢复时隔离保留，避免自动合并覆盖恢复结果；不属于导出备份 |

旧“导出账户资料与工作区”文件仍可供查阅，但没有本版的来源签名，不作为可恢复备份。未来格式、改动过的文件、其他账户及其他安装产生的文件会被拒绝并说明原因。

## 数据保护

- 备份格式 `tracer-workspace-backup` v1 包含版本、创建日期、来源空间、工作区、白名单偏好、SHA-256 校验及 HMAC 来源签名。签名密钥保存在本机账户索引，不包含在下载文件中。
- 预览不会修改工作区。提交时重新校验文件，并在工作区写队列内核对预览对应的基线；预览后有新编辑或购买时，必须重新预览。
- 恢复前快照独立写入当前空间的 `.backups/`，写成功才开始提交。无法写快照、文件无效、过大或当前有数据操作时，不替换工作区。
- 工作区通过临时文件原子替换。恢复标记与恢复内容在同一文件中提交，服务端拒绝旧窗口继续读写或擦除该标记。
- 浏览器恢复偏好前，先保存原白名单偏好和旧草稿的隔离记录。偏好写入失败会尝试回滚并锁定页面，重新打开可重试；不会自动执行旧草稿。
- 桌面伙伴按恢复标记重新载入，过期的伙伴操作和创建请求被拒绝。
- “清空账户本地资料”也会清除该账户的恢复前快照和浏览器隔离草稿；另行下载的文件不在清理范围内。

备份文件上限 8 MB；恢复后的工作区连同必要恢复信息仍须满足现有 4 MB 存储限制。当前主工作区和 `.bak` 都损坏时，本版不提供覆盖坏档的 UI 恢复：保留原文件并先做人工救援，避免抹掉剩余线索。

## 开发与验收

后端：`lib/workspace-backup.js`、账户 provider、账户 HTTP 与普通存储请求的恢复标记检查。前端：`public/backup-preferences.js`、`account-storage.js`、`workspace-backup.js` 和账户入口。

相关单元测试：

```powershell
node --test test/workspace-backup.test.js test/backup-preferences.test.js test/backup-storage.test.js test/pet-desktop.test.js
```

真实 HTTP 与浏览器演练：

```powershell
$env:TRACER_QA_PLAYWRIGHT = (Resolve-Path '.cache/desktop-qa-tools/node_modules/playwright').Path
node dev/qa-workspace-backup.cjs
```

QA 使用独立源码运行副本、临时数据和合成凭据；不读取日常 `local.config.json`、真实账户或工作区。结果与截图位于 `.cache/workspace-backup-*`。安装包升级、外部试用和换机恢复不属于这些自动测试的覆盖范围。
