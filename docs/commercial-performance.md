# B09 首轮英语与桌面性能检查

日期：2026-09-28。本轮核验 Windows 源码运行版，未制作安装包，也未完成 macOS、低配置机器或外部试用验收。

## 修复内容

- 项目切换不再在路由刷新后重复重建看板；任务编辑、删除、清除已完成及语言切换复用当前页面刷新。隐藏的看板在下次进入时读取最新任务。
- 保留任务编辑的回调，以及保存成功或冲突合并后的必要刷新；“重建一次”指同一次同步项目切换，不要求整个保存生命周期永远只渲染一次。
- 主按钮悬停保留主题强调色背景，修复深底黑字。四个时段的对比度在真实浏览器检查。
- 托盘的打开与退出入口提供英文；原生浏览器首次启动默认英语，语言切换更新面板自有文字并保留导航状态。
- 网页版 Tracer 参考栏使用 `Reference URL`，不显示开发用的 `fixture source`。其他皮肤未声明该覆盖项时保持原有文案。
- 项目复盘中的英文记录说明改为适用于单条和多条记录的表达。

## 测量方式

使用 `dev/qa-commercial-performance.cjs` 建立独立源码运行副本、随机端口和三个新 Electron profile。合成工作区包含 500 项任务、10 个项目、500 条专注历史和一条笔记；不加载日常配置、账户、凭据或数据。

本机为 Windows x64、Intel Core i7-14650HX、24 个逻辑处理器、约 23.71 GiB 内存；Electron 44.3.0、Chromium 152.0.7977.78、Playwright 1.63.0。测试窗口固定为 1000×720、非全屏；操作采样时显式确认主窗口可见且已激活。全局输入钩子关闭，不测试自定义动态主题、AI 或云服务。

启动测三次，每次使用新 profile，但不清理操作系统磁盘缓存。操作测五次，报告事件触发至第二个动画帧的耗时，另保留同步执行和 CDP 脚本/布局指标。空闲状态各测三组，每组约三秒。

## 前后比较和证据边界

可靠的直接改进：两个方向的项目筛选，每次完整看板重建由 **2 次降至 1 次**，修改前后各有五次真实 UI 观测，另有针对当前/隐藏视图的行为回归。

早期测试误选了伙伴窗口作为原生窗口目标，后段帧等待和后台时长不可信。`.cache/b09-performance-G7kJ0P/report.json` 已标记无效时间数据，不能与最终耗时作加速比较；只保留正确主页面观测到的重建次数。最终脚本精确选择主窗口并核验原生与渲染器可见状态。

可信报告为 `.cache/b09-performance-fSNXZ7/report.json`。其 `sourceHashes` 与最终 hash/编辑时序说明记录了 Reader 文案修正与采样重叠；看板去重、任务和计时核心逻辑在最终采样期间保持不变。原生语言另作最终源码的独立检查，不把这组性能结果当作最终安装包验收。


性能采样和英语流程测试应顺序运行，避免彼此干扰。测试脚本会自行创建临时数据；原生性能测试会短暂展示测试窗口并验证最小化、隐藏及恢复。

本轮相关自动回归 18/18 通过，日志为 `.cache/b09-regression/tests.log`。英语与中英窄屏 QA 95/95 通过，证据为 `.cache/commercial-english-um5Ud7/summary.json`；最终原生语言检查 3/3 通过，证据为 `.cache/native-language-vNuxse/summary.json`。四时段主按钮悬停文字对比度均达到 4.5:1。截图已复核，测试进程均已关闭。
