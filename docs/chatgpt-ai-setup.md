# 使用 ChatGPT 套餐规划任务

1. 安装 Tracer 0.3.4 或更新版本。
2. 打开 **AI 计划 → 我的 AI → ChatGPT 套餐登录**。
3. 点击 **使用 ChatGPT 账号登录**，再点击 **打开 OpenAI 登录页面**。
4. 在系统浏览器中登录自己的 ChatGPT 账号并确认授权。保持 Tracer 打开，授权结果会自动返回。
5. 回到 Tracer，点击 **测试连接**。出现“模型测试成功”表示模型确实返回了响应。
6. 在“计划需求”填写目标、截止日期和每周工时。可选上传资料，生成并检查草案后，确认创建任务。

这个流程使用官方 Codex App Server 及账号包含的 Codex 额度。ChatGPT 套餐并不提供通用 OpenAI API 免费额度；Tracer 的“自己的 API”选项是另一种接入方式。套餐额度耗尽或无法确认时，Tracer 会停止请求，等待额度恢复，不自动购买或转用 API。

默认浏览器授权不需要设备验证码授权开关，也不要求修改 MFA。登录失败可取消后重新发起，并保持浏览器与 Tracer 在同一台电脑运行，以完成本机回调。

凭据由官方组件存入系统凭据库，Tracer 使用独立登录空间。退出此账号不会退出其他 Codex 应用。生成时仅主动提交目标、时间要求、所选资料和勾选的未完成任务；执行命令、网页搜索、应用连接和多代理功能关闭。

## 从源码构建

`npm run dist` 会下载锁定版本的官方 Windows x64 Codex 运行时，校验归档及每个文件的哈希，并随安装包附带许可证。首次构建需要访问官方 npm 注册表。运行时文件只保存在构建缓存和安装产物，不提交到源码仓库。

官方说明：[Codex 登录](https://learn.chatgpt.com/docs/auth)、[App Server](https://learn.chatgpt.com/docs/app-server)。
