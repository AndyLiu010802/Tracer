# 桌面 3D 花园

在任务花园选择「搬到桌面」即可启用透明的桌面花园；默认关闭，位置和窗口大小会保存。顶部可以拖动窗口，拖动岛屿可以旋转，滚轮调整视角缩放，Ctrl + 滚轮调整窗口大小。方向键旋转，Home 恢复视角。成熟植物上的勾选按钮可以收获；保存成功后与主窗口同步。

岛屿使用 WebGL 三维地形、分层岩壁、池塘、小径和各地区建筑。建筑包含屋瓦、窗框、门廊、灯具与花盆。地面采用六地区手绘材质，并通过起伏、岸边碎石、草丛及种植处的柔和土色过渡衔接植物。植物结合程序生成的实体结构和生成插画构成的封闭浮雕网格；属于三维与插画混合表现，旋转时有厚度，并非完整雕刻的植物模型。

渲染按变化触发，不使用持续动画循环。设备像素比上限为 1.75，只保留当前六株植物所需的纹理与网格。隐藏或锁定账户时释放 GPU 资源；恢复显示重新创建。WebGL 上下文丢失后可恢复。桌面操作带账户范围、会话和序号校验；收获由主窗口的持久化模型处理。

## 同批功能

项目星球支持六地区的柔和混合地表。明信片共十二款，新增八款价格为 70–160 金币；已有贴纸可重复用于明信片，每张最多 24 个，支持移动、缩放、旋转和删除，并以 2400 × 1600 导出。

神秘礼包的十万个等概率票号分配为：装饰 70.899%，100 金币 20%，500 金币 8%，2,000 金币 1%，50,000 金币 0.1%，自动钓鱼马达 0.001%。金币奖励按开包收据唯一入账，重复打开不会重复发放。

## 验证

`test/garden-desktop-3d.test.js` 覆盖植物池、历史收据兼容、普通植物图集、六地区网格与封闭植物厚度。`desktop/test/garden.test.js` 覆盖账户授权、重放防护、窗口边界和生命周期。

`dev/qa-desktop-garden.cjs` 使用真实 Electron 验证桌面展示、收获、缩放、旋转、空闲停止绘制、上下文恢复、六地区截图、隐藏后资源清理、恢复窗口大小及账户锁定。`dev/qa-world-expansion.cjs` 验证明信片、贴纸、导出、移动布局和礼包展示。
