# 桌面花园

在任务花园选择「搬到桌面」即可启用桌面花园，位置和大小会保存。0.4.7 仅使用软件内同一套地区美术、植物和摆件，不再提供 3D 环绕模式。

鼠标移入花园时显示顶部名称、打开与关闭按钮，移开隐藏；没有底部说明条。拖动顶部移动花园，Ctrl + 滚轮或右键菜单调整大小。成熟植物上的勾选按钮可以收获，保存后与主窗口同步。

植物生长阶段、翻页和摆件的位置、大小、朝向、镜像与收起状态均同步。空闲时不持续绘制，隐藏或锁定账户时释放场景。

## 同批功能

项目星球支持六地区的柔和混合地表。明信片共十二款，新增八款价格为 70–160 金币；已有贴纸可重复用于明信片，每张最多 24 个，支持移动、缩放、旋转和删除，并以 2400 × 1600 导出。

神秘礼包的十万个等概率票号分配为：装饰 70.899%，100 金币 20%，500 金币 8%，2,000 金币 1%，50,000 金币 0.1%，自动钓鱼马达 0.001%。金币奖励按开包收据唯一入账，重复打开不会重复发放。
