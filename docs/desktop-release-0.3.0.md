# Tracer Desktop 0.3.0

## 本版内容

- 使用用户提供的原始黑底金色星月 Logo，转换为应用、托盘、网页标识与多尺寸桌面 ICO。
- 中英双语 AI 计划助手：目标与资料、时间与工时、计划预览、账号与服务。
- PDF、DOCX 和 UTF-8 文本资料在本地工作线程中提取文字；发送前需用户明确同意。
- 统一服务登录、邀请码注册、服务器密钥保管、每日调用额度。桌面登录令牌通过 Windows 安全存储加密。
- 根据截止日期、工作日、每周/每天工时、单次工作时长、弹性时间和已有任务占用计算日程。任务可修改估时并重算。
- 确认后创建项目、分段任务和摘要笔记；重复确认不重复创建，已有任务与完成历史保留。

## 下载与升级

`dist/Tracer-Setup-0.3.0-x64.exe` 是 Windows x64 安装程序，包含 35 段原有音频；不含个人工作区、账号或云端密钥。退出托盘中的旧版后安装，使用原安装位置即可保留数据。安装程序创建桌面快捷方式。

`dist/Tracer-AI-Service-0.3.0.zip` 是独立部署包。请按 [AI 服务开通指南](ai-service-setup.md) 操作。服务未部署前，AI 生成不可联网使用；任务管理、番茄钟等本地功能可正常使用。

安装包目前未购买代码签名证书，因此 Authenticode 状态为 `NotSigned`。发布前可在 `dist/SHA256SUMS-0.3.0.txt` 核对文件哈希。

## 验证范围

- 既有 Node 测试与新增 AI 计划、账号、额度、文件解析测试通过；桌面独立测试通过。
- 打包后的 Electron 应用使用独立测试工作区验证中英文 UI、账号注册、服务连接、资料同意、预览、容量不足阻止创建、追问修订、确认落盘、历史保留和加密登录。
- 打包后实际执行 PDF、Word、文本读取工作线程。
- 安装包内容检查个人数据隔离、版本与批准的 Logo；部署 ZIP 解压后启动服务并检查健康端点。
- AI 提供商测试使用可控响应，未使用真实密钥、未产生真实模型调用。没有云服务器和 Docker 运行环境，尚未进行公网 HTTPS / Docker 启动验收。部署配置已提供，需在目标服务器按指南验证。

## 尚未包含

此版账号是 AI 服务账号，不是跨设备任务同步。当前按天和工时排程，未连接外部日历，也不做扫描 PDF 的 OCR。邀请制服务使用单实例文件数据库；扩容之前需迁移数据库并补齐正式运营监控。
