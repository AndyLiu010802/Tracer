Tracer for macOS — Apple Silicon and Intel

- Apple 芯片（M 系列）：下载 `Tracer-版本-mac-arm64.dmg`。
- Intel 芯片：下载 `Tracer-版本-mac-x64.dmg`。
- 打开 DMG，将 Tracer 拖入 Applications（应用程序），再启动 Tracer。无需另装 Node.js 或 Codex。
- 本地任务、笔记、完成历史与设置保存在 `~/Library/Application Support/tracer-desktop/`。
- 支持 Command+C/V/X/Z/A、Command+Q、Control+Command+F；点击 Dock 图标可恢复已隐藏的窗口。
- 花园后台输入计数是可选功能。在 Tracer 菜单中启用，并按系统提示授予辅助功能权限；按需检查输入监控权限，重新启动应用。未授权时仍可使用任务、笔记、专注与窗口内计数。
- 各架构附件附带 SHA-256 校验文件。

发布者检查：本草稿在两种架构构建、签名、公证及启动检查完成后生成。正式发布前，还需在 Mac 上确认窗口操作、资料导入、音频、桌宠、输入权限和真实账号 AI 登录。
