# 统计与完成记录

## 使用

- 左侧「统计」查看完成趋势、当前任务分布、最近 91 天完成日历和历史明细。
- 选择近 7 / 30 / 90 天、全部历史，或自定义起止日期；也可按项目或历史文字搜索。
- 点击图表柱形或日历日期，可查看对应区间的记录。
- 点击历史任务标题，查看完成当时的标题、编号、项目、负责人、截止日期和完成时间。
- 「导出 CSV」导出当前筛选下的全部记录，不只导出当前页。时间使用 UTC 并在表头标注；页面显示本地时间。

## 保存规则

每次任务进入已完成状态时，会把快照写入工作区的 `completionHistory`。修改标题、重开、删除任务或删除项目，都不删除已有完成记录。重新完成同一任务新增一条事件，因此「完成次数」与「完成过的任务数」可能不同。

点击任务移动提示上的「撤销」，会添加一条撤销标记：原始事件保留，但不计入趋势和完成明细。普通重新打开任务不会撤销真实完成历史。

旧任务有明确 `doneAt` 时可以补入历史。没有完成时间的旧任务不伪造日期，统计页显示缺失提示。功能启用以前已经删除、且没有可用完成时间的数据无法自动还原。

本地工作区保存仍采用串行写入、临时文件原子替换和上一版 `.bak` 备份。完成记录合并在同一写入队列内；旧客户端省略该字段时也保留已有历史。云端同一账户保存采用相同保留规则，共享模块已同步到微信小程序源码，尚未部署至微信云端。

历史不会按时间自动清理。仍需保留应用数据目录，删除整个数据目录会丢失记录；可定期导出 CSV 作额外备份。超出既有工作区容量限制时会报保存失败，不会自动删除历史以腾出空间。

## 统计口径

- 完成趋势和明细：按完成事件的本地日期，首尾日期均包含在内。
- 当前任务分布：当前任务状态，不按历史日期筛选；跟随项目筛选。
- 完成日历：最近 91 天，跟随项目和历史文字筛选。
- 专注分钟：番茄钟最近 500 轮本机记录，跟随日期，不按任务搜索或项目过滤；不代表所有设备的专注时长。

## 验证

`test/task-history.test.js` 覆盖快照、重开、删除、撤销、旧数据补入、合并、串行落盘和日期边界。云端测试覆盖旧客户端删任务后保留完成历史。

`dev/qa-insights.js` 使用隔离浏览器和模拟任务 API，覆盖历史显示、分页、搜索、日历筛选、快照详情、导出、真实状态控件写入、刷新持久化、中英切换与窄窗口布局。
