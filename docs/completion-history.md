# 统计与完成记录

## 使用

- 左侧「统计」查看完成趋势、当前任务分布、最近 91 天完成日历和历史明细。
- 选择近 7 / 30 / 90 天、全部历史，或自定义起止日期；也可按项目或历史文字搜索。
- 选择单个项目时显示只读复盘卡；也可在项目看板点击“项目复盘”。已归档项目仍可在统计页选择。复盘依据该项目全部保留记录，不随日期与历史搜索变化；下方原有统计继续使用各自筛选口径。
- 点击图表柱形或日历日期，可查看对应区间的记录。
- 点击历史任务标题，查看完成当时的标题、编号、项目、负责人、截止日期和完成时间。
- 「导出 CSV」导出当前筛选下的全部记录，不只导出当前页。时间使用 UTC 并在表头标注；页面显示本地时间。

## 保存规则

每次任务进入已完成状态时，会把快照写入工作区的 `completionHistory`。修改标题、重开或删除单个任务，不删除已有完成记录；删除整个项目会同时清除该项目的任务、笔记和完成记录。重新完成同一任务新增一条事件，因此「完成次数」与「完成过的任务数」可能不同。

点击任务移动提示上的「撤销」，会添加一条撤销标记：原始事件保留，但不计入趋势和完成明细。普通重新打开任务不会撤销真实完成历史。

旧任务有明确 `doneAt` 时可以补入历史。没有完成时间的旧任务不伪造日期，统计页显示缺失提示。功能启用以前已经删除、且没有可用完成时间的数据无法自动还原。

本地工作区保存采用串行写入、临时文件原子替换和上一版 `.bak` 备份。完成记录合并在同一写入队列内；旧客户端省略该字段时也保留已有历史。项目删除标记会阻止旧数据重新带回已删除项目的内容。

历史不会按时间自动清理。仍需保留应用数据目录，删除整个数据目录会丢失记录；可定期导出 CSV 作额外备份。超出既有工作区容量限制时会报保存失败，不会自动删除历史以腾出空间。

## 统计口径

- 完成趋势和明细：按完成事件的本地日期，首尾日期均包含在内。
- 当前任务分布：当前任务状态，不按历史日期筛选；跟随项目筛选。
- 完成日历：最近 91 天，跟随项目和历史文字筛选。
- 已记录专注分钟：来自本空间最多 500 个保留的完整番茄钟轮次，按日期和项目筛选；历史搜索只筛完成记录。初次显示与计时器实时刷新使用同一规则。
- 专注项目优先采用轮次保存的项目快照，包括当时明确没有项目的情况。旧轮次缺少该字段时，才根据当前任务或唯一的历史完成项目推断，并在复盘卡提示；无法归属的不计入单项目卡。任务后来移动项目不会改写有明确快照的旧轮次。
- 相同专注轮次只计一次，互相冲突的重复记录和无效记录排除；统计页不会修改或修复存档。

## 单项目复盘

复盘卡分别展示历史完成过的任务、当前任务估时、手填工时及已记录专注。历史完成数按任务去重，当前完成/保留卡片数单独说明；清除卡片或重新打开任务后，这些值可能不同，不作为整体项目完成率。

估时与手填工时使用现存任务卡上的小时数，缺失显示“—”，数值 0 与空值区分。部分 AI 创建任务的手填字段默认为 0，因此“有数值”不意味着用户已填报实际投入。完成历史未保存估时和手填工时，清除任务卡后无法还原这些数值。

差值只比较同时有估时和保留专注记录的同一组现存任务：已记录专注分钟减去估时小时 × 60；没有匹配任务时不计算。手填工时不与计时记录相加。未完成任务也可能进入这组对照，差值不是实际超时、节省工时或效率评分。

番茄钟只在整轮结束时记入专注历史，未结束、取消或任务提前完成后重置的部分时间不计入。全空间保留最近 500 轮；达到上限或累计时长超过现存明细时显示记录范围提示。没有记录不能推断为没有工作，最早/最晚记录也不是完整项目工期。

## 验证

`test/task-history.test.js` 覆盖快照、重开、删除、撤销、旧数据补入、合并、串行落盘和日期边界。`test/project-deletion.test.js` 覆盖项目删除及旧数据回写保护。

`dev/qa-insights.js` 使用隔离浏览器和模拟任务 API，覆盖历史显示、分页、搜索、日历筛选、快照详情、导出、真实状态控件写入、刷新持久化、中英切换与窄窗口布局。

`test/insights-model.test.js` 覆盖项目归属、估时/手填/专注口径、清除卡片、重复与无效记录、保留上限及只读行为。`dev/qa-project-review.cjs` 使用独立运行副本、真实本地服务和合成数据，验证项目入口、实时更新、日期/搜索边界、归档项目、中英文与窄屏，不读取真实配置或用户数据。
