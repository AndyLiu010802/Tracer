# Tracer 0.4.0 — 本地账户与专属伙伴

本次版本加入本地账户、花园金币商店和九种异色伙伴专属鼠标拖尾，并改进笔记贴纸、外观材质与任务拖拽。

## 账户与外观

- 本地注册、登录、账户切换、恢复码和账户资料管理；工作区、金币、已购物品与偏好按账户隔离。保留云服务接口，本版不提供邮箱验证码或跨设备云同步。
- 头像支持上传后手动调整位置与缩放、背景配色和十二星座图案；内置图案默认黑色，可自行换色。
- 壁纸商店提供静态、动态和材质外观各 10 款，使用种植所得金币购买并保存到当前账户。动态效果与玻璃、水晶、金属、木质等材质随对应设计呈现。
- 贴纸背包改为悬浮球，只在笔记中出现；贴纸可在笔记内直接拖动、从四周缩放及旋转。

## 花园与伙伴

- 任务进行时种植，完成后成熟；清除已完成任务只移除卡片，成熟花朵留在花园等待手动收获。
- 花园收藏、布局和家具商店；项目归档后保留花朵星球。
- 九种异色伙伴各有专属拖尾：月露花径、日冕金穗、薰风星穗、青苹果汽露、桃霞流绢、樱吹雪、霓虹蝶兰、莓电回路、极光晶棱。
- 在「桌宠小屋 → 照料」或悬浮伙伴面板中开启、关闭拖尾，每位伙伴分别记忆；普通伙伴不显示专属开关。停止移动后粒子消散，动画随之停止。
- 新账户金币仍从 0 开始，测试补款不会随安装包分发。

## 流畅度与兼容性

- 修复外观边框影响任务拖拽定位，覆盖缩放、滚动和跨列移动场景。
- 窗口隐藏时暂停壁纸与材质绘制，专注计时仍可在后台完成；恢复窗口后继续呈现动画。
- 修复 Mac 全屏窗口的最小化操作，以及菜单栏引起的鼠标拖尾纵向偏移。
- 继续支持 Windows x64、Apple 芯片 Mac 与 Intel Mac。发布流程分别在对应原生云端运行环境构建，检查打包应用启动、账户隔离、伙伴动画、拖尾、保存恢复及后台计时；三平台全部通过后统一发布。

## 安装

从本发布页选择 `Tracer-Setup-0.4.0-x64.exe`（Windows）、`Tracer-0.4.0-mac-arm64.dmg`（Apple 芯片）或 `Tracer-0.4.0-mac-x64.dmg`（Intel Mac）。Mac 同时提供 ZIP，统一 `SHA256SUMS-0.4.0.txt` 用于核对下载。

更新前从系统托盘完全退出旧版，再安装到原位置。已有任务、笔记、账户、伙伴和购买记录保留；无需另装 Node.js 或 Codex。

Windows 安装包目前未签名；Mac 使用 ad-hoc 签名，尚无 Apple Developer ID 签名与公证。真实账号 AI 登录、系统输入授权与第三方独占全屏软件不在自动化测试覆盖范围内。
