## 第一步：技术基线与首个真实任务引导

日期：2026-09-28。

本次实现一项可独立验证的首次使用改进。用户访谈、定价、支付和商家开通尚未执行；本次结果不代表已验证市场需求，也不代表十二周计划全部完成。

### 已完成的改动

- 看板增加中英文入门卡：输入一个真实的小步骤，创建进行中任务并种下对应种子；复用现有任务与花园模型。
- 任务保存成功后可以打开已关联的专注计时器，由用户自己开始；已有未结束的专注不会被替换。
- 用户明确选择“我已完成这项任务”后保存完成状态，再进入花园收获；计时结束不自动完成任务。
- 空白且没有历史记录的工作区自动显示引导；已有用户默认不显示，可以通过“入门引导 / Getting started”重新打开。
- 收起状态和未提交标题按现有本地账户隔离保存；切换语言和重新加载保留输入与进度。
- 保存失败保留同一任务和种子，允许重试；工作区冲突、账户切换或锁定时禁止引导写入。
- 同账户多窗口创建使用浏览器共享锁。其他窗口发现入门任务变化但尚未加载任务时，先提示重新载入，不再次创建。
- 使用现有英语默认设置、计时器、任务保存和账号隔离实现，没有新增第三方服务、遥测或依赖。

### 修改范围

新增 `skins/tracer/getting-started-model.js`、`getting-started.js`、`getting-started.css`。在 `index.html` 注册资源，在 `board.js` 挂载引导，在 `app.js` 和 `wellness.js` 发出本地保存/专注状态事件。

新增 `test/getting-started.test.js` 和 `dev/qa-getting-started.cjs`。保留工作区中原有伙伴、素材及其他未提交修改，没有自动提交或发布安装包。

### 后续调整：任务完成、番茄钟与下一项任务联动

根据 2026-09-28 的使用反馈补齐循环：

- 当前计时器关联的任务完成并保存后，自动停止计时、清除任务关联和本轮闹钟，恢复用户设定的专注时长；已完成的专注历史、累计时长、轮次与设置保留。
- 运行中、暂停及本轮已结束的计时器均可复位。完成其他任务不影响当前计时；保存失败不提前复位，重试成功后再处理。
- 引导任务的花朵收获并保存成功后，从花园回到看板第一步，显示空白输入框并自动聚焦；新建下一任务使用新的任务与种子，保留此前的完成和收获记录。
- 收获失败时停留花园供用户重试；收获其他花朵或已收起引导时不强制跳转。多窗口操作使用现有账户共享锁，并重新核验最新计时器及引导任务，避免旧保存结果清除新任务。

实现涉及 `focus-model.js`、`wellness.js`、`getting-started-model.js`、`getting-started.js`，以及对应模型、保存边界和浏览器回归。

本次相关单元测试共 45 项通过：`focus-model` / `wellness-input` 共 17 项，`getting-started` / `tracer-sync-client` 共 28 项；覆盖启动恢复、失败重试、账户锁定、跨窗口替换与不虚增专注历史。本次未重复全量测试，也未重新打包安装程序。

最终源码的 Edge 浏览器回归共 65 项全部通过，无运行错误或外部请求；包括收获失败后重试、自动返回并聚焦、连续创建第二个任务，以及运行/暂停计时器的完成联动。证据为 `.cache/getting-started-uhPaNx/summary.json` 和同目录截图；计时器测试日志为 `.cache/commercialization-baseline/task-completion-timer-tests.log`。另经只读审查，未发现收获重置与多窗口创建之间的阻塞问题。

## 第二步：B07 本机快照备份与恢复

日期：2026-09-28。已交付当前安装、同一账户或游客空间的工作区回退；具体范围见[本机快照备份说明](workspace-backup.md)。B07 的跨设备迁移、资源完整打包和外部用户演练尚未交付，不能将本轮称为完整一键迁移。

### 已完成的改动

- 账户面板新增中英文备份入口；游客无需注册，也可下载和恢复。
- 使用版本化、带内容校验和本机来源签名的 JSON；只接受当前安装、同一空间签发的备份。旧资料导出、篡改、未知版本和跨账户文件有明确反馈。
- 选择文件后预览数量及范围，再明确确认恢复；预览后有新保存时拒绝过期提交。
- 恢复前独立保存可下载快照，快照写成功才原子替换工作区。当前工作区保留到提交成功；可下载旧快照，再次预览并撤销恢复。
- 工作区、花园经济与收藏整体回滚，不将旧资产叠加到现有资产。专注记录和设置恢复，但不自动启动计时、不补算过期专注或响铃。
- 只恢复明确白名单中的界面偏好；账户、凭据、许可和未包含的本机资源保持独立。伙伴图片等需另用伙伴包，不暗示已经包含。
- 恢复标记阻止旧窗口和迟到的响应回写；旧工作区草稿隔离保留。桌面伙伴同步重新载入，并拒绝旧恢复状态下的操作。
- 清空账户资料时也清除该账户的隔离草稿，不遗留新增恢复功能产生的隐私记录。

- 修复原统计页按项目筛选时仍混入其他项目专注分钟的问题；初次显示与计时器实时更新共用同一计算规则。
