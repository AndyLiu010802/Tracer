## 水中原画

主窗口鱼塘、桌面鱼塘、主窗口水族馆和桌面水族馆通过 `fishing-species-live.js` 使用现有 156 种 imagegen 原画。读取鱼苗实例的 `speciesId` / `fishId`，避免把实例编号当成物种。

原画贴在同一个 WebGL 场景内的细分曲面上，沿用原有游动路径、底栖位置、成长比例和投喂轨迹。按鱼、鳐、长体鱼、水母、腕足及甲壳类分配变形方式；方向变化连续压缩、翻转鱼身。它是原画曲面的动态渲染，不是新雕刻的全体积鱼模型。水面、缸壁、地形与装饰继续通过场景深度参与遮挡。未知物种或图片加载失败时保留原模型回退。

## 资源与性能

- 每种当前住鱼裁取 384 × 256 图集格子上传，重复物种共用纹理。5 条鱼塘鱼和 3 条水族馆鱼合计约 3 MiB GPU 鱼纹理；未入住物种不上传整页图集。
- 一条鱼每个渲染通道只提交一次绘制。更换住鱼立即释放退出物种的 GPU 纹理，销毁窗口后异步图片不能恢复旧场景。
- 绘制遵循原生 `tracer-visibilitychange`：主窗口被收起时停止鱼塘/水族馆 RAF，重新显示时重置时间，避免补跑隐藏期间的动画。
- 普通 1× 屏幕按实际像素绘制，不再强制 1.5× 缓冲区；高分屏仍支持最高 1.75×。异步图片完成及状态更新合并到已有动画帧。

[实测数据](../output/fishing-live-species/report.json) 比较相同生产场景、相同鱼种的新原画路径与旧模型路径；单位为 RAF 绘制回调脚本耗时，不代表整机 CPU 或完整 GPU 帧耗时。结果受设备、窗口大小和系统负载影响。
