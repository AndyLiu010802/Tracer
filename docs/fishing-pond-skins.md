## 美术文件与构建

- `art-source/fishing-pond-skins/<id>.blend`：10 个真正的 Blender 4.5.14 LTS 工程，包含可编辑的建筑、倒角、法线、材质、灯光、相机；岸边图像已打包进工程。
- 同目录 `<id>.glb`：便于其他 3D 工具使用的环境模型。演示用水塘不包含在游戏模型中。
- `skins/tracer/fishing-art/pond-skin-<id>-scene-v1.json / .bin`：实际游戏加载的合并网格，不依赖运行时安装 Blender。
- `*-bank-v1.png / *-box-v1.png`：内置 imagegen 逐个生成的 20 份岸边材质及配套箱子图，均已复制进项目。完整提示词与原始来源见 [美术清单](fishing-pond-skin-art-manifest.json)。
- `*-preview-v1.png`：游戏 WebGL 直接渲染的商品缩略图；商店列表使用静态缩略图，仅展开的预览创建 3D 上下文。
- `dev/build-fishing-pond-blender.py`：可复现的 Blender 建模、导出脚本；`-- all` 重建全部，`-- konoha` 等参数重建指定主题，`-- --pack-existing` 对已有工程打包并重新导出。

```powershell
& '.cache/blender-pond-tools/blender-4.5.14-windows-x64/blender.exe' --background --factory-startup --threads 6 --python dev/build-fishing-pond-blender.py -- all
node dev/qa-fishing-pond-skins.cjs
```

## 玩法与存档

皮肤只更换岸边材质和环境建筑。原钓场的轮廓、水体、鱼种分布、饵料倾向、价格、鱼苗、鱼群动作、抛竿与溜鱼机制继续使用现有数据。建筑按当前钓场岸线定位，参与真实遮挡和阴影。玩家已有摆件保留。

购买使用确定 ID 的 `pond_skin` 交易凭据，相同套装的离线重复购买在合并时只扣款一次。装备写入独立时间戳 `pondAppearance`，避免较新的无关存档覆盖已装备外观。旧存档不强制新增字段；未购买外观不能装备。主程序与桌面端只传递白名单皮肤 ID。

截图中的神秘礼物说明段落已隐藏，礼物开启、自动钓鱼马达概率与相关成就均保留。
