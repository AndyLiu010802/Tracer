# 桌面饵料盒

点击鱼塘右下角的小木盒，或右键鱼塘 → 打开饵料盒。展开窗口为 320 × 208 DIP，相比之前的 564 × 334 占用面积减少约 65%。优先与鱼塘并排、底边对齐；右侧空间不足时放在左侧，两侧都不足时才放在上方，并限制在当前屏幕工作区。盒子独立、透明、置顶，拖住盒盖可移动，关闭按钮或 Esc 收起。

右下角的小盒子采用等角透视矢量模型，包含顶盖、正面、侧板、把手、黄铜包角、铆钉、搭扣与接触阴影。展开盒盖和托盘以轻微透视倾斜，增加侧板厚度、内凹格槽与遮蔽阴影；保留五格鱼饵与右键菜单，价格完整说明仍在原生菜单和辅助文本中。

五格沿用统一的手绘鱼饵，展示库存、每袋价格与已装备标记。右键鱼饵可装备、补充一袋（10 份），或一次购买并装备。左键和键盘 Enter / Shift+F10 也能打开同一个原生菜单，左右方向键切换格子。所有操作均留在桌面，商店仍可使用。

垂钓中和存档中锁定购买、换装；空库存不能装备，余额不足不能购买。菜单执行时重新校验当前账号、还原记录、钓鱼会话与库存；同一个菜单回调只能执行一次。关闭再打开盒子会使旧菜单失效。账号切换或主窗口关闭时销毁盒子并清理监听。

主窗口控制器继续持有真实钱包与存档。购买并装备合用一次持久化；保存失败显示重试按钮，重试原有收据，不重复扣费或加饵。菜单和预加载接口不接收自定义价格、数量或奖励。
