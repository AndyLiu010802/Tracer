# 渔场递进、隐藏保底与立体原画鱼

| 顺序 | 渔场 | 永久解锁金币 | 新鱼获基础售价倍率 |
| --- | --- | ---: | ---: |
| 1 | 芦苇溪塘 | 免费 | 1 |
| 2 | 珊瑚海塘 | 400 | 1.2 |
| 3 | 霜镜冰塘 | 1,000 | 1.5 |
| 4 | 幽蓝深潭 | 2,200 | 1.8 |
| 5 | 灵莲仙池 | 4,500 | 2.2 |
| 6 | 云月天池 | 8,500 | 2.6 |

先解锁上一渔场，再购买下一渔场；购买后自动进入。访问资格由永久交易凭证推导，重复点击不扣费。余额不足和跨级访问同时在 UI 与模型层阻止。旧版本已经实际垂钓过的渔场及此前各级保留访问权。

新鱼获售价为物种原价乘渔场倍率并四舍五入，再应用黄金竿双倍或爆能器浮动。定价在抛竿记录中锁定，换塘、换竿不会改变旧鱼获的价值。新鱼苗成年收获为其出生渔场基础售价的 150%。旧捕获、旧收获和旧交易保持原值，避免追溯变更存档余额。

0.4.4 使用第二版经济规则。此前源码预览版的高倍率捕获（`valueRevision:1`）及旧解锁交易仍按原规则校验，不追改已发生的扣款、收益与鱼苗价值。新捕获写入 `valueRevision:2`，相关新交易写入 `economyRevision:2`。

解锁成本约覆盖上一阶段数十至百余条普通鱼获；高品质鱼、养成和鱼竿效果可加快进度。礼包原价不变，保留解锁渔场与收藏鱼竿之间的金币选择。

每个礼包集齐 `rodIds` 中所有常规鱼竿（不含隐藏款）后，从下一抽开始独立累计隐藏保底。自然概率仍为 0.5%；最多第 100 抽强制隐藏款，优先于史诗/传说保底。自然或保底获得隐藏款均归零。单抽与十连共享计数，十连逐抽结算。已集齐的老玩家直接开启，但旧抽数不追溯累计；历史凭证不改写。

渔场背景：内置 imagegen 生成六景图集，文件为 `skins/tracer/fishing-art/grounds-landscape-v1.png`。完整提示词与工具记录见 `fishing-ground-art-v1.json`。CSS 按图集位置显示六景，无额外图标。

游动鱼：`fishing-species-live.js` 读取现有生成原画透明轮廓，构建正反两面的圆润厚度网格，并使用原画 UV、真实世界朝向、表面法线光照及尾鳍变形。鱼身不再按镜头方向压缩宽度。该方案是由单视图推导的立体表面，并非每个物种独立雕刻的解剖模型；背面复用原画。纹理和网格只为当前居民加载，移除或销毁时释放。

验证：`test/fishing-ground-progression.test.js` 覆盖解锁、余额、存档、鱼价、养成、保底边界与十连；`test/fishing-species-live.test.js` 覆盖转身厚度、加载与资源释放。`dev/qa-fishing-ground-progression.cjs` 检查桌面与窄屏 UI；`dev/qa-fishing-live-species.cjs` 在真实 WebGL 中检查 156 种鱼、遮挡、喂食、隐藏窗口停帧及 GPU 错误。截图位于 `output/fishing-progression/` 和 `output/fishing-live-species/`。
