# Tracer 0.3.4 — ChatGPT 套餐登录

新增通过 OpenAI 官方 Codex 组件登录 ChatGPT 的方式。使用账号包含的 Codex 额度，无需配置 API 密钥或部署服务器；原有个人 API 和本机模型设置继续保留。

- 默认使用系统浏览器进行官方授权，无需开启设备验证码授权。
- 计划只需回答目标、截止日期、每周工时三个问题；资料和高级设置可选。
- 区分“已登录”和“模型测试成功”，计划预览确认后才创建任务。
- 使用独立的系统凭据存储，不读取已有 Codex 登录文件。分享的安装包不含账号、密钥或任务。
- 生成前检查套餐额度；额度耗尽或无法确认时停止，不购买额度、不自动转用付费 API。
- 修复切换 AI 接入方式时，较慢的状态请求覆盖当前配置的问题。

## 使用

安装 `Tracer-Setup-0.3.4-x64.exe`，打开 **AI 计划 → 我的 AI → ChatGPT 套餐登录**，点击登录，再打开官方授权页面。完成后返回 Tracer，点击“测试连接”。

需要账号可用的 Codex 套餐额度及网络连接。套餐额度受 OpenAI 限制；本软件不提供无限量 AI。自己的 API 模式按所选服务商的规则计费。
