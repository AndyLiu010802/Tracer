# 项目庆祝与异色精灵提醒

项目通过「完成并生成星球」归档且成功保存后，整个应用窗口底部、左侧、右侧会分批喷出彩纸。纸片翻转后自然飘落，约 5.7 秒自动结束，也可点击庆祝提示右侧关闭。特效不拦截页面操作；减少动态效果模式保留文字祝贺，不喷射彩纸；窗口隐藏时停止绘制。

彩纸采用六款单独生成的透明 PNG：金箔、珊瑚和纸、幻彩菱片、鼠尾草纤维纸、冰蓝珠光纸、玫瑰金缎带。通过内置 image_gen 生成，原图保存在 `skins/tracer/celebration-art/*-v1.png`，提示词及来源路径见 `prompts-v1.json`。运行时只缓存小尺寸绘制纹理，不修改原始素材。

异色种子在首次成熟且成功保存时，弹出对应精灵、名称和来源任务。未收获时提供「去花园收获」，已经收获时可打开伙伴收藏。没有改变概率、随机结果、金币或解锁条件。

提醒仅根据保存成功前后的变化产生。已完成的历史记录不会在启动时重新庆祝；保存失败时不触发，重试成功后才触发。提醒在当前本地账户内去重，待展示队列可跨刷新恢复。编辑弹窗、输入操作或窗口隐藏期间等待展示，原编辑内容和焦点不被覆盖。

验证：`test/celebrations.test.js`、`test/tracer-sync-client.test.js`、`dev/qa-celebrations.cjs`。浏览器检查覆盖保存失败重试、三边喷射、六张素材加载、去重、队列恢复、真实精灵图像、键盘关闭、移动端和减少动态效果。
