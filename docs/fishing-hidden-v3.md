# 隐藏鱼竿技能与多鱼收获更新

2026-10-10。更新工作区开发版，不修改用户账户或旧鱼获，不生成安装包。

爆能器重新召唤使用独立的待机展示阶段，不再继承上次捕获/脱钩的隐藏状态。装备时提前异步加载装置原画，展示位置为装置留出边距；入场不阻塞投掷输入。

爆能器的 3–5 条鱼与身外身的 2–3 条鱼分别从水面跃出，错开 65 ms，分开落点并落地跳动。每条鱼使用本次结算的真实种类。多鱼层位于环绕与技能层前方，避免实色特效遮挡鱼获。桌面窗口直接用会话里的鱼类 ID 选择现有鱼类图集，不需要加载完整规则目录，也不新增鱼类 WebGL 上下文。

概率提高 30% 按原概率乘 1.3 处理，不是增加 30 个百分点。概率以中鱼为条件；杂物和神秘礼物不触发鱼类奖励。

| 隐藏鱼竿 | 新规则 |
| --- | --- |
| 黄金鱼竿 | 保留每次售鱼双倍金币，100% 生效。 |
| 万象归墟 | 直接上鱼由 15% 调整为 19.5%。 |
| 齐天大圣·身外身 | 双鱼由 16% 调整为 20.8%，三鱼由 6% 调整为 7.8%，合计 28.6%。 |
| 传国玉玺 | 替换减张力能力：32.5% 触发「天命敕令」，目标提升一个品质，最高传说，仍取自当前钓场。 |
| 鸣人·六道仙人 | 替换溜鱼救援能力：39% 触发「六道生息」，锁定当前钓场可育苗鱼，成功收获的鱼苗初始成长为 50%。 |
| 路飞·太阳神尼卡 | 替换直接上鱼和断线救援：26% 触发「解放之鼓」，等待缩短 55%，成功收鱼后返还本次 1 份饵料，保留手动溜鱼。 |
| 爆能器 | 保留必定获得 3–5 条鱼，每条售价独立为基础价的 50%–150%，不获得鱼苗。 |

三国与火影为重做后的新触发概率；原有保底、抽箱概率及必定生效的技能不变。界面会显示新技能名称和收益说明，鱼竿详情同步更新。

新普通钓鱼使用 rules 7，爆能器使用 rules 8。旧 rules 2–6 和早期无版本记录仍按原规则校验。返饵由成功鱼获凭据推导，取消、脱钩和杂物不返饵；重复结算、重复读取和存档合并不会多返。新增技能不接受界面伪造结果。

验证：

- 新机制 8 项测试通过：12,000 个种子概率抽样、各钓场品质提升/育苗、成长与返饵、失败不返饵、重复结算/合并、旧 rules 5/6 捕获及出售、多鱼连续轨迹、无完整目录的桌面绘制。
- 钓鱼及桌面钓鱼/水族箱共 433 项测试全部通过，无失败或跳过。覆盖输入、存档、结算、动画、资源及桌面通信。完整日志：[verification.log](../output/fishing-hidden-v3/verification.log)。
- 真实浏览器加载生产模块：从待机/捕获/脱钩状态召唤爆能器；爆能器 3/4/5 条、身外身 2/3 条在主界面与桌面两个界面均通过种类、可见性、边界、独立位置和结束清理检查。三种新技能提示通过，无页面异常或缺失资源。参见 [运行结果](../output/fishing-hidden-v3/runtime.json)。
- 鱼竿与鱼类收藏图集已重新构建，资源来源校验同步更新。浏览器检查使用临时测试场景和合成存档，不访问用户账户。
