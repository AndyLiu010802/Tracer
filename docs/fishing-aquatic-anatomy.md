# 水生生物造型与动作核对

本次新增 50 种，按身体结构分别建模。幻想种保留装饰变化，肢体数量与运动仍沿用其原型。这里记录的是游戏模型采用的简化结构，不是分类学标本。

- 普通蟹显示四对步足；帝王蟹显示三对步足，寄居蟹显示两对主要行走足。螯与行走足分开。帝王蟹结构依据 [NOAA 红帝王蟹资料](https://www.fisheries.noaa.gov/species/red-king-crab)，寄居蟹结构参照 [NOAA 蟹类观察指南](https://www.fisheries.noaa.gov/s3/2023-09/2023-Crab-Guide.pdf)。
- 章鱼使用八腕；乌贼为八腕加两条摄食触腕，吸盘和腕体使用相同的形变。鹦鹉螺单独使用 90 条细触手与漏斗，不画章鱼吸盘。依据 [Smithsonian 头足类资料](https://ocean.si.edu/ocean-life/invertebrates/octopuses-squids-and-relatives) 与 [Monterey Bay Aquarium 鹦鹉螺资料](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/chambered-nautilus)。
- 虾、龙虾采用六段腹节链和末端尾扇；龟与六角螈采用四肢，壳体、颈部与头部连接；贝类围绕同一铰链开合。
- 蟹、寄居蟹、龙虾采用两段逆运动学步足，腿长在抬足和落足时固定。龟与六角螈使用固定骨长的四肢摆动，螯肢围绕关节转动。腹节链每段长度固定。
- 蟹侧行，螺类缓慢滑行，贝类原地开合，海胆以管足慢移，水母伞体脉动。底栖种以足底高度贴近缸底，并避免翻滚。减弱动态设置冻结肢体相位。
- 图鉴与游戏使用同一套几何模型。动画由父子关节矩阵和顶点形变驱动，没有使用通用摆尾去移动甲壳类肢体。
