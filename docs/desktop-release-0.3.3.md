# Tracer 0.3.3 — 自选 AI，三问规划

AI 计划助手改为用户自行填写 API 地址、模型和密钥，无需 Tracer 账号、邀请码或云端部署。支持 OpenAI Responses、兼容 Chat Completions 的接口，以及用户已启动的本机模型服务。

计划需求只问目标、截止日期和每周可用工时。资料上传及高级时间设置默认折叠；AI 仅在缺少关键信息时补充最多两个问题。保留计划预览、编辑、容量检查和确认后创建任务。

- 新增“保存并测试”，区分保存配置与实际模型回复。
- 桌面版使用可用的系统加密保存密钥；无安全存储时仅保留在进程内存。更换服务地址需重填密钥。
- 支持中英文及窄屏布局，保留现有任务和完成历史。

## 使用

安装 `Tracer-Setup-0.3.3-x64.exe` 后，打开 **AI 计划 → 我的 AI**。填写个人 API 配置并测试，再回到“计划需求”生成草案。AI 服务商可能收取调用费，安装包不包含任何真实密钥。

## 验证与限制

个人接口、凭据保存规则、计划校验及排程自动化测试通过；界面测试覆盖中英文和 420 / 760 / 1440 像素宽度，验证预览不改任务、确认后保存及历史记录保留。使用隔离的测试模型接口，没有调用真实付费 AI，不能据此声称用户密钥或所有第三方服务已连接。

本机此前的独立 EXE 启动被 Windows Device Guard 拦截。本次构建不代表该系统策略问题已解决，也没有自动替换现有安装；需要设备管理员允许应用运行后才能完成安装启动验证。

旧云端部署包不再是本版本的使用前提；本版仍不提供跨设备任务同步。
