# 钓鱼扩展与西游降魔

> 旧弹窗验证入口已退役；本文中的相关命令为历史记录。当前验证方式见 [桌面与原画验证](fishing-live-species-upgrade.md)。

当前目录为 56 种鱼、14 种鱼饵、6 个渔场和 58 款鱼竿。鱼种与鱼饵从本轮开始前的 28 / 7 扩展为 56 / 14；新增第三套「西游降魔」20 款鱼竿。页面标题采用「我的鱼塘」「鱼竿收藏」「钓具商店」等功能名称。

## 渔场与鱼饵

每次抛竿固定渔场、时段、天气和水层。六个渔场分别对应河流、海水、冰湖、深潭、灵莲和云月鱼群；冰塘保留鳟鱼、河鲈，深潭保留鲭鱼，灵莲保留鲤鱼、锦鲤，云月保留鳟鱼。所有 56 种鱼都能从对应渔场获得。鱼饵不会把其他渔场的鱼带入当前鱼池。

上鱼概率为 82% + 鱼饵加成 + 天气与时段加成，上限 96%。微雨 +2.5 个百分点，多云 +1 个百分点，清晨或黄昏 +1.5 个百分点。神秘礼包保持 3%；剩余概率为杂物。鱼饵加成为 2–9 个百分点，偏好鱼种在当前渔场内的权重乘以 3；不匹配鱼饵仍可钓到该渔场的全部鱼种。

蓄力不足 38% 为近岸，38–75% 为中水，76% 及以上为深水。匹配水层权重 ×1.7；匹配时段栖息地权重 ×1.4；微雨时珍稀和史诗鱼权重 ×1.2。更换渔场会保存；时段和天气现已改为设备定位与真实时间自动获取，不能手动选择。正在进行的一竿使用抛竿时的条件，详见[成熟收获与真实天气](fishing-harvest-weather.md)。

图鉴提供栖息地筛选、鱼饵偏好、捕获次数和个人最大尺寸。钓手经验与 8 项成就从真实捕获记录计算，出售鱼不会清除记录。

## 隐藏鱼竿

| 鱼竿 | 生效规则 |
| --- | --- |
| 黄金鱼竿 | 鱼获出售金币 ×2；杂物和礼包不翻倍。 |
| 万象归墟 | 鱼咬钩时 15% 概率直接收鱼，跳过提竿与控竿小游戏；这类收获不计完美捕获。 |
| 齐天大圣·身外身 | 16% 概率两条、6% 概率三条；其余单条。一次最多三条，只扣一份鱼饵。杂物和礼包不触发。 |

多鱼结果产生独立鱼获记录；符合条件时逐条奖励鱼苗，并可分别出售。结算重试和账户合并不重复扣饵或发奖，存档验证拒绝超出三条、不完整批次及重复批次索引。三个奖池分别保底，隐藏款均为每抽固定 0.5%。旧存档和已经存在的捕获、鱼苗、喂养记录继续保留。

13 款西游高级鱼竿使用内置 image_gen 逐件生成的透明原画。原画存放于 `skins/tracer/fishing-art/summon-journey-*-v1.png`，完整提示词、相对路径和 SHA-256 摘要见[原画清单](fishing-journey-vfx-art.json)。原画通过连续网格变形，按各自的冠羽、武器、衣袖、枝叶、铃铛和轮轴区域设置动作，随后沿真实竿身曲线收束成形。

`fishing-spell-effects.js` 将蓄力聚集、抛竿飞行、落水、咬钩、持续收线和捕获收尾分开。天雷鼓采用一次稳定分叉放电和水面震纹；不会每帧随机闪烁。小游戏期间降低特效强度，虚影放在鱼竿侧，保留水面与控竿区域。减少动态效果时使用低强度静态提示；WebGL 不可用时以 Canvas 回退。

## 投喂与成长

投喂达到 100% 时提示成年，逐步长大并展示成年饰纹；成年鱼解锁对应的额外动作，之后仍可投喂。新增 28 种鱼各有独立投喂描述与动作；新增传奇鱼也加入水族箱的泳姿和空间边界限制。

## 验证

- `node --test test/*.test.js`：模型、概率、养成、结算、同步、界面与原有功能回归。
- `node --test desktop/test/*.test.js`：桌面行为回归。
- `node dev/desktop-pack-assets.cjs`：桌面包包含全部脚本和原画。
- `node dev/qa-fishing-journey-vfx.cjs`：隔离渲染 13 款西游虚影及天雷鼓，检查透明通道、多个动作时刻、裁切、GPU 错误、Canvas 回退、减少动态效果与资源释放，并生成实际游戏截图。产物位于 `output/fishing-upgrade-qa/`，不读写真实账户。
